# Hangman

A word guessing game with 40 words, on-screen keys and a chalk drawn gallows.

## Features

- 40 words with hints
- Six lives, shown by the drawing revealing part by part
- On-screen keyboard plus physical keyboard support
- Win and loss states that reveal the answer
- New word button to start again

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
